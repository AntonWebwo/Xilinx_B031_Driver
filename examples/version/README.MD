# Version Examples

Примеры получения и анализа версии прошивки FPGA для идентификации платформы и совместимости драйвера.

## Описание

Драйвер считывает идентификатор версии из регистра `HARDWARE_VERSION` (ID 0). Этот регистр содержит уникальный код платформы, который позволяет программному обеспечению адаптировать логику работы под конкретное аппаратное обеспечение (например, V9 для Antminer S19).

**Ключевые значения:**
- **0xB031**: Платформа V9 (Xilinx Zynq 7007), используемая в Antminer S19 и более новых моделях.

## API Функции

```c
// Получение полной информации о версии (ID и строковое описание)
int fpga_get_version(fpga_version_info_t* info);

// Быстрое получение только числового идентификатора версии
uint32_t fpga_get_version_id(void);
```

Структура информации:
```c
typedef struct fpga_version_info_s {
    uint32_t version_id;      // Числовой ID (например, 0xB031)
    char firmware_ver[32];    // Строковое описание платформы
} fpga_version_info_t;
```

## Примеры

### test_version.c

Утилита для быстрой проверки типа установленной контрольной платы. Выводит числовой ID версии, строковое описание и статус совместимости с ожидаемой платформой V9.

**Компиляция:**
```bash
arm-linux-gnueabihf-g++ -static -std=c++11 -lpthread test_version.c ../zynq7007_fpga_driver.c -o test_version
```

**Использование:**
```bash
sudo ./test_version
```

**Пример вывода (успешный):**
```
================================================================================
 FPGA VERSION CHECK (Zynq 7007 Driver V9)
================================================================================
 Version ID   : 0xB031
 Firmware     : V9 Platform (0xB031)
 Platform     : V9 (Zynq 7007) [MATCH]
 Status       : OK
================================================================================
```

**Пример вывода (несовместимость):**
```
================================================================================
 FPGA VERSION CHECK (Zynq 7007 Driver V9)
================================================================================
 Version ID   : 0xA020
 Firmware     : V9 Platform (0xB031)
 Platform     : Unknown / Legacy
 Warning      : Expected 0xB031 for V9 platform
================================================================================
```

## Особенности реализации

1. **Регистровая карта**: Чтение производится из самого первого регистра (`HARDWARE_VERSION`, логический адрес 0), что гарантирует минимальное время отклика при старте системы.
2. **Валидация**: Утилита автоматически сравнивает полученный ID с эталонным значением `0xB031` и выдает предупреждение в случае несовпадения, что критично для предотвращения ошибок при работе с разными поколениями оборудования Bitmain.
3. **Статическая сборка**: Как и все примеры в репозитории, бинарный файл собирается статически для обеспечения максимальной переносимости между различными версиями прошивок майнеров.
