# PWM Examples

Примеры управления скоростью вращения вентиляторов (PWM) и мониторинга оборотов через драйвер Zynq7007 FPGA.

## Описание

Управление вентиляторами на платформе V9 осуществляется через запись значений duty cycle (рабочего цикла) в регистры `FAN_CONTROL` (ID 19) и `FAN_CONTROL_1` (ID 23). Чтение скорости (RPM) производится через регистр `FAN_SPEED` (ID 1), который содержит данные от тахометров вентиляторов.

**Логика работы:**
- **Группа 0 (`FAN_CONTROL`)**: Управляет вентиляторами FAN0 и FAN1.
- **Группа 1 (`FAN_CONTROL_1`)**: Управляет вентиляторами FAN2 и FAN3.
- **Duty Cycle**: Значение от 0 до 100%. В регистре записывается инвертированное значение для логики ШИМ контроллера Bitmain.
- **Чтение RPM**: Драйвер автоматически определяет физический ID вентилятора и применяет коэффициент масштабирования (`0x78` или 120) для получения реальных оборотов.

## API Функции

```c
// Инициализация подсистемы вентиляторов
int fpga_fan_init(void);

// Получение текущей скорости вращения в RPM
int32_t fpga_fan_get_speed(fan_id_e fan_id); // fan_id: FAN0-FAN3

// Установка скорости вращения (Duty Cycle 0-100%)
int fpga_fan_set_speed(fan_id_e fan_id, uint8_t duty_cycle);

// Включение всех вентиляторов на максимальную скорость
int fpga_fan_turn_on(fan_side_e side);

// Выключение всех вентиляторов
int fpga_fan_turn_off(fan_side_e side);
```

## Примеры

### test_fan.c

Универсальная утилита для тестирования, мониторинга и автоматической проверки работоспособности системы охлаждения.

**Компиляция:**
```bash
arm-linux-gnueabihf-g++ -static -std=c++11 -lpthread test_fan.c ../zynq7007_fpga_driver.c -o test_fan
```

**Использование:**

1. **Мониторинг в реальном времени:**
   Отображает текущие обороты всех четырех вентиляторов с обновлением каждую секунду.
   ```bash
   sudo ./test_fan --monitor
   ```

2. **Установка скорости:**
   ```bash
   # Установить всем вентиляторам 50% мощности
   sudo ./test_fan --set 50
   
   # Установить только первой группе (FAN0, FAN1) на 75%
   sudo ./test_fan --set 0 75
   
   # Установить только второй группе (FAN2, FAN3) на 100%
   sudo ./test_fan --set 1 100
   ```

3. **Автоматический тест (Auto-test):**
   Пошагово изменяет скорость от 1% до 100% с паузами для стабилизации, выводя показания тахометров на каждом этапе.
   ```bash
   sudo ./test_fan --auto-test
   ```

## Особенности реализации

1. **Маппинг логических ID**: 
   - Логический `FAN0` соответствует физическому ID 1.
   - Логический `FAN1` соответствует физическому ID 0.
   - Логические `FAN2` и `FAN3` соответствуют физическим ID 2 и 3 соответственно.
2. **Расчет RPM**: Формула расчета: `Raw_Value * 0x78`. Это специфичный коэффициент для платформы B031.
3. **Запись в регистры**: При установке скорости драйвер формирует 32-битное значение, где младшие биты содержат инвертированный duty cycle, а старшие — прямой.
4. **Безопасность**: Функция `fpga_fan_set_speed` ограничивает входное значение диапазоном 1-100%.
