# UART Examples

Примеры работы с последовательным интерфейсом (UART) для коммуникации с ASIC чипами хэш-плат через регистры FPGA.

## Описание

Драйвер реализует механизм Broadcast Mode (BC) для отправки команд и приема ответов от ASIC. Взаимодействие происходит через буферные регистры FPGA (`BC_COMMAND_BUFFER`) и FIFO приема (`RETURN_NONCE`). 

**Ключевые особенности:**
- **Скорость (Baud Rate):** Устанавливается напрямую в регистр `FPGA_BT8D` (ID 15). Индекс `0x1A` (26) соответствует стандартной скорости 115200 бод.
- **Режим VIL:** Для корректной работы буферов отправки необходимо активировать бит `VIL_MODE` (15-й бит) в регистре `DHASH_ACC_CONTROL`.
- **CRC5:** При отправке данных драйвер автоматически рассчитывает и добавляет контрольную сумму CRC5 к первым 4 байтам пакета.
- **Таймауты:** Настраиваются через регистр `TIME_OUT_CONTROL`.

## API Функции

```c
// Полная инициализация UART (установка baud rate 115200 и таймаутов)
int fpga_uart_full_init(void);

// Очистка FIFO приема и сброс счетчика ошибок CRC
int fpga_uart_clear_fifo(uint32_t chain_id);

// Отправка данных (минимум 4 байта) с автоматическим расчетом CRC5
int fpga_uart_bc_send(uint32_t chain_id, const uint8_t *data, uint32_t size);

// Прием ответа с ожиданием (timeout в мс)
int fpga_uart_bc_receive(uint32_t chain_id, fpga_uart_rx_result_t *result, int32_t timeout_ms);

// Расчет CRC5 (используется внутри драйвера)
uint8_t bitmain_crc5(const uint8_t *data, uint32_t len_bits);
```

## Примеры

### 1. test_uart_tx.c

Утилита для прямой отправки сырых данных (HEX) на указанную цепь с возможностью выбора индекса скорости.

**Компиляция:**
```bash
arm-linux-gnueabihf-g++ -static -std=c++11 -lpthread test_uart_tx.cpp ../zynq7007_fpga_driver.c -o test_uart_tx
```

**Использование:**
Отправка команды `52 05 00 00 0A` на Chain 0 со скоростью 115200 (индекс 26):
```bash
sudo ./test_uart_tx 0 520500000A 26
```

### 2. test_uart_rx.c

Утилита для мониторинга входящего трафика из FIFO ASIC. Выводит полученные данные в формате HEX построчно.

**Компиляция:**
```bash
arm-linux-gnueabihf-g++ -static -std=c++11 -lpthread test_uart_rx.cpp ../zynq7007_fpga_driver.c -o test_uart_rx
```

**Использование:**
Прослушивание Chain 0 в течение 30 секунд на скорости 115200:
```bash
sudo ./test_uart_rx 0 30 26
```

## Особенности реализации

1. **Регистровая карта:** 
   - `FPGA_BT8D` (ID 15) — делитель частоты для UART.
   - `BC_COMMAND_BUFFER` (ID 28-30) — буфер для записи отправляемых данных.
   - `RETURN_NONCE` (ID 4) и `RETURN_NONCE_HI` (ID 5) — регистры для чтения принятых слов из FIFO.
   - `NONCE_NUMBER_IN_FIFO` (ID 6) — счетчик доступных для чтения слов.
2. **Формат данных:** Данные передаются словами по 32 бита (4 байта). При приеме утилита распаковывает каждое слово в 4 отдельных байта в порядке Big Endian.
3. **Блокировка:** Все операции отправки и приема защищены мьютексом `uart_mutex` для предотвращения коллизий при многопоточном доступе.
4. **Очистка FIFO:** Перед началом приема рекомендуется вызывать `fpga_uart_clear_fifo`, чтобы избавиться от старых или некорректных данных.
