# LED Examples

Примеры управления светодиодными индикаторами контрольной платы (RED, GREEN) через драйвер Zynq7007 FPGA.

## Описание

Светодиоды на плате Antminer S19/V9 подключены к GPIO портам FPGA и управляются через SysFS интерфейс Linux. Драйвер предоставляет функции для прямого включения/выключения, а также для реализации сложных световых паттернов (мигание, стробоскоп).

**Поддерживаемые светодиоды:**
- **Red LED** - GPIO 941 (ID 0 в API)
- **Green LED** - GPIO 942 (ID 1 в API)

## API Функции

```c
// Прямое управление состоянием светодиода
int fpga_led_control(int led_id, int on); // led_id: 0=Red, 1=Green; on: 0=OFF, 1=ON

// Мигание с заданным периодом и количеством циклов
int fpga_led_blink(int led_id, int count, int period_ms);
```

## Примеры

### test_led.c

Универсальная утилита для тестирования всех режимов работы светодиодов, включая прямой контроль, программируемое мигание и динамический "полицейский" режим.

**Компиляция:**
```bash
arm-linux-gnueabihf-g++ -static -std=c++11 -lpthread test_led.c ../zynq7007_fpga_driver.c -o test_led
```

**Использование:**

1. **Прямое управление состоянием:**
   ```bash
   # Включить красный светодиод
   sudo ./test_led --red 1
   
   # Выключить зеленый светодиод
   sudo ./test_led --green 0
   ```

2. **Программируемое мигание:**
   Мигает указанным цветом заданное количество раз с указанным периодом (в миллисекундах).
   ```bash
   # Мигать красным 5 раз с периодом 100мс
   sudo ./test_led --blink red 100 5
   ```

3. **"Полицейский" режим (Police Mode):**
   Запускает многопоточный цикл со сложным паттерном стробоскопа (красный/зеленый) и случайными акцентами. Работает до нажатия `CTRL+C`.
   ```bash
   sudo ./test_led --police
   ```

## Особенности реализации

1. **SysFS GPIO**: Управление осуществляется через запись значений `1` или `0` в файлы `/sys/class/gpio/gpio<N>/value`.
2. **Автоматическая настройка**: Драйвер автоматически экспортирует GPIO пины и устанавливает направление `out` при первом обращении.
3. **Многопоточность**: Режим `--police` использует отдельный поток (`pthread`) для выполнения светового паттерна, что позволяет корректно обрабатывать сигнал прерывания (`SIGINT`) для плавного завершения работы.
4. **Статическая сборка**: Бинарный файл собирается статически для независимости от системных библиотек на устройстве.
