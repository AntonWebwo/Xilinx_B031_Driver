# GPIO Examples

Примеры работы с линиями общего назначения (GPIO) и аппаратным управлением сбросом хэш-цепей.

## Описание

В данном разделе представлены утилиты для низкоуровневого управления состоянием RESET пинов ASIC чипов. В отличие от кнопок, которые читаются через SysFS, управление сбросом осуществляется путем прямой записи в регистры FPGA (`RESET_HASH_BOARD`), что обеспечивает мгновенную реакцию и точное соблюдение временных интервалов, требуемых протоколом инициализации Bitmain.

**Логика работы:**
- Регистр `RESET_HASH_BOARD` (ID 13) управляет состоянием пинов RI (Reset Input).
- Установка бита в `1` активирует сброс (логический `0` на пине, Active Low).
- Сброс бита в `0` снимает напряжение сброса (логическая `1` на пине), позволяя ASIC начать инициализацию.

## API Функции

```c
// Аппаратный сброс конкретной цепи с соблюдением таймингов (10ms hold, 50ms settle)
int fpga_reset_chain_hw(uint32_t chain_id);

// Низкоуровневое чтение/запись регистра сброса (для ручного контроля)
int fpga_reg_read(uint32_t address, uint32_t* val);
int fpga_reg_write(uint32_t address, uint32_t val);
```

## Примеры

### reset_chain.c

Утилита для программного или ручного управления сбросом хэш-плат. Поддерживает два режима работы: автоматический импульс сброса и ручное удержание пина в состоянии Reset.

**Компиляция:**
```bash
arm-linux-gnueabihf-g++ -static -std=c++11 -lpthread reset_chain.c ../zynq7007_fpga_driver.c -o reset_chain
```

**Использование:**

1. **Автоматический сброс (стандартный импульс):**
   Выполняет последовательность: Assert Reset -> Wait 10ms -> Release Reset -> Wait 50ms.
   ```bash
   sudo ./reset_chain -c 0
   ```

2. **Ручное управление (Manual RI Control):**
   Позволяет зафиксировать плату в состоянии сброса или принудительно вывести её из него.
   ```bash
   # Удержать Chain 1 в состоянии сброса (RI LOW)
   sudo ./reset_chain -c 1 --ri 0
   
   # Снять сброс с Chain 1 (RI HIGH)
   sudo ./reset_chain -c 1 --ri 1
   ```

3. **Справка:**
   ```bash
   ./reset_chain --help
   ```

## Особенности реализации

1. **Потокобезопасность:** Хотя прямая запись в регистр не блокируется глобальным мьютексом UART/I2C, функция `fpga_reset_chain_hw` реализована как атомарная операция с выверенными задержками `usleep`.
2. **Диагностика:** После успешного выполнения автоматического сброса утилита автоматически опрашивает регистр `HASH_ON_PLUG` для подтверждения физического наличия платы на канале.
3. **Ограничение цепей:** Для платформы V9 (S19) поддерживаются цепи с ID от 0 до 3.
4. **Статическая сборка:** Бинарный файл собирается статически (`-static`) для гарантированного запуска на любых версиях прошивок Antminer без зависимости от системных библиотек.
