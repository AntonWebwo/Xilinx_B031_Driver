# FPGA Register Examples

Примеры низкоуровневой работы с регистрами AXI FPGA платформы V9 (0xB031).

## Описание

Данный раздел содержит инструменты для прямого чтения и записи регистров FPGA через memory-mapped I/O. Это позволяет проводить глубокую диагностику, отладку протоколов взаимодействия и мониторинг состояния аппаратных блоков в реальном времени.

**Важно:** Драйвер ограничивает доступ к логическим адресам регистров диапазоном **0-115**. Попытка обращения к регистрам с индексом выше 115 вернет ошибку.

## API Функции

```c
// Чтение значения из регистра по логическому адресу
int fpga_reg_read(uint32_t address, uint32_t* val);

// Запись значения в регистр по логическому адресу
int fpga_reg_write(uint32_t address, uint32_t val);

// Получение физического адреса по логическому индексу (для отладки)
uint32_t get_fpga_physical_address(uint32_t logical_address);
```

## Примеры

### fpga_reg_tool.c

Универсальная утилита командной строки для дампа всех регистров, чтения конкретного регистра или записи значения. Поддерживает ввод адресов и значений как в десятичном, так и в шестнадцатеричном формате (`0x...`).

**Компиляция:**
```bash
arm-linux-gnueabihf-g++ -static -std=c++11 -lpthread fpga_reg_tool.c ../zynq7007_fpga_driver.c -o fpga_reg_tool
```

**Использование:**

1. **Полный дамп регистров (0-115):**
   ```bash
   sudo ./fpga_reg_tool dump
   ```
   *Вывод включает имя регистра, логический ID, физический адрес и текущее значение в HEX.*

2. **Чтение конкретного регистра:**
   ```bash
   # Чтение регистра версии оборудования (ID 0)
   sudo ./fpga_reg_tool read 0
   
   # Чтение регистра скорости вентилятора (ID 1) в HEX формате
   sudo ./fpga_reg_tool read 0x01
   ```

3. **Запись в регистр:**
   ```bash
   # Установка скорости UART 115200 бод (запись 0x1A в регистр FPGA_BT8D, ID 15)
   sudo ./fpga_reg_tool write 15 0x1A
   ```

## Карта основных регистров (V9 Platform)

| Логический ID | Имя регистра | Описание |
| :--- | :--- | :--- |
| 0 | `HARDWARE_VERSION` | Версия прошивки FPGA |
| 1 | `FAN_SPEED` | Текущая скорость вращения вентиляторов (RPM) |
| 2 | `HASH_ON_PLUG` | Статус подключения хэш-плат (битовая маска) |
| 8-11 | `TEMPERATURE_X_Y` | Данные с температурных датчиков ASIC |
| 12 | `IIC_COMMAND` | Регистр управления шиной I2C |
| 13 | `RESET_HASH_BOARD` | Управление сбросом хэш-цепей (Active High в регистре) |
| 15 | `FPGA_BT8D` | Настройка baud rate UART |
| 19 | `FAN_CONTROL` | Управление PWM вентиляторов 0 и 1 |
| 23 | `FAN_CONTROL_1` | Управление PWM вентиляторов 2 и 3 |
| 26 | `BC_WRITE_COMMAND` | Триггер отправки данных по UART (Broadcast) |
| 28-30 | `BC_COMMAND_BUFFER` | Буфер данных для отправки по UART |
| 33 | `CRC_ERROR_CNT` | Счетчик ошибок CRC при приеме данных |

## Особенности реализации

1. **Логическая адресация:** Пользователь работает с последовательными индексами (0, 1, 2...), которые драйвер транслирует в физические адреса согласно карте `v9_fpga_map`.
2. **Безопасность:** Инструмент проверяет границы массива имен регистров и наличие маппинга перед выполнением операции.
3. **Формат вывода:** Все значения выводятся строго в шестнадцатеричном формате (`0x%08X`) для удобства сравнения с документацией и логами анализаторов.
4. **Права доступа:** Требуется запуск от имени root для доступа к `/dev/axi_fpga_dev`.
